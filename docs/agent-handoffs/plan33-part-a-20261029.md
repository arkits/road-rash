## For other sessions

- **Golden change:** the `raster-rgb-alloc` pin moved from `0x861b81d25eb5f7db` to
  `0xbab29462f0960895`. The old value depended on AppleClang FMA contraction,
  which is now off everywhere. No other golden changed.
- **SDL:** the desktop/web pin is 3.4.18 and Android stays on 3.4.8. A system
  SDL older than 3.4 now builds the pinned source. Linux containers without
  X11/Wayland headers need `-DRR_SDL_HEADLESS=ON`.
- **New lint:** CTest `portability-lint` fails on a new unannotated `std::sort`,
  platform libm calls, `__int128` or unguarded POSIX headers in `src/`.
